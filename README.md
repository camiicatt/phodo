# phodo

one pic a day. just for your people.

A photo-diary social app for iPhone: post one moment a day, and it becomes a page in your journal. Friends see it in a feed that ends. No likes, no follower counts.

## Run it

```bash
brew install xcodegen
xcodegen generate
open phodo.xcodeproj
```

Then press ⌘R (run) or ⌘U (tests) in Xcode.
